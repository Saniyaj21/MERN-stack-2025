### **Introduction to the Web**

#### **What is the Web?**
The **World Wide Web (WWW)** is a system of interconnected documents and resources, accessed via the internet. It allows users to navigate between pages using hyperlinks.

#### **Web Components**
1. **Client**: The user's device (e.g., browser) that requests and displays web pages.
2. **Server**: A computer that hosts and delivers web content.
3. **Protocols**: Rules for communication (e.g., HTTP, HTTPS).
4. **Web Pages**: Documents written in HTML, styled with CSS, and made interactive with JavaScript.
5. **URL (Uniform Resource Locator)**: The address used to access web resources.

#### **HTTP Protocols**
- **HTTP (Hypertext Transfer Protocol)**: A protocol for transferring web pages between a server and a client.
- **HTTPS (HTTP Secure)**: A secure version of HTTP that encrypts data using SSL/TLS.

#### **Web Technologies**
- **Frontend**: HTML, CSS, JavaScript.
- **Backend**: Server-side languages like Python, PHP, Node.js.
- **Databases**: MySQL, MongoDB, PostgreSQL.
- **Frameworks**: React, Angular, Django.

### **Basics of Networking**

#### **What is a Network?**
A network is a group of interconnected devices (computers, servers, etc.) that communicate and share resources.

#### **Types of Networks**
1. **LAN (Local Area Network)**: A network within a small area, like a home or office.
2. **WAN (Wide Area Network)**: A network that spans large geographical areas (e.g., the internet).
3. **MAN (Metropolitan Area Network)**: A network within a city or campus.
4. **PAN (Personal Area Network)**: A network for personal devices (e.g., Bluetooth).

#### **IP (Internet Protocol)**
- **IPv4**: A 32-bit address format (e.g., `192.168.1.1`). Limited to ~4.3 billion addresses.
- **IPv6**: A 128-bit address format (e.g., `2001:0db8:85a3::8a2e:0370:7334`). Solves IPv4's limitations.

### **Web Hosting and Domain**

#### **Web Hosting**
Web hosting is a service that allows individuals or organizations to make their websites accessible on the internet. Hosting providers store website files on servers.

#### **Domain Name System (DNS)**
- **DNS**: A system that translates human-readable domain names (e.g., `google.com`) into IP addresses (e.g., `172.217.10.46`).
- **Domain Name**: The address users type to access a website (e.g., `example.com`).

#### **Hosting Platforms**
- **Shared Hosting**: Multiple websites share the same server resources.
- **VPS (Virtual Private Server)**: A virtualized server with dedicated resources.
- **Cloud Hosting**: Hosting on a network of interconnected servers.
- **Dedicated Hosting**: An entire server dedicated to one website.

---


### **Summary**
- The **web** is a vast network of interconnected resources accessed via the internet.
- **Networking** involves connecting devices to share resources, with IP addresses enabling communication.
- **Web hosting** and **domain names** are essential for making websites accessible to users.

---

### **Example: How the Web Works**
1. A user types a URL (e.g., `https://example.com`) into their browser.
2. The browser sends an HTTP request to the DNS server to resolve the domain name into an IP address.
3. The DNS server returns the IP address of the web server hosting the site.
4. The browser sends an HTTP request to the web server.
5. The web server responds with the requested web page (HTML, CSS, JS files).
6. The browser renders the web page for the user.

---

### **Key Terms**
- **Client-Server Model**: A structure where clients request resources from servers.
- **Protocol**: A set of rules for communication.
- **IP Address**: A unique identifier for devices on a network.
- **Domain Name**: A human-readable address for websites.
- **Hosting**: Storing and serving website files on a server.
